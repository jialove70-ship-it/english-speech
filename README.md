# From Operating Room to Publication

A buildless, single-page English presentation adapted from the supplied 13-slide PowerPoint by Chih-Chien Wu, MD (SCRS Taiwan Annual Meeting / ICRSF 2026).

Open `index.html` directly, or serve this directory with a static HTTP server. All styling, speaker notes, and progressive enhancement JavaScript are embedded. There are no third-party scripts, fonts, or runtime dependencies. The preferred font is Microsoft YaHei, using local fallback fonts on devices where it is unavailable.

## GitHub Pages

Publish this directory as the repository root (or place it in `/docs` and select that folder). In Settings → Pages, select **Deploy from a branch**, the deployment branch, and **/(root)** (or `/docs`, matching the chosen layout). The included `.nojekyll` keeps the site buildless.

The source presentation’s operative figure citation is retained; the operative image itself is omitted.
